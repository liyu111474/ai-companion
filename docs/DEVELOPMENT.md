# 开发与验收

## 本地开发

在项目根目录工作；先查看 `git status --short --branch` 和 `git diff`，保留已有修改。针对本次需求定义可检查的结果，再修改相关文件。行为问题先添加可复现的回归用例。

本应用使用 Streamlit，参考 Skill 项目流程中的目标、验收和公开检查规则；`init_skill.py`、`SKILL.md`、用户技能目录同步和 `quick_validate.py` 属于 Skill 项目，不作为本应用的验收步骤。

## 行为检查

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

没有项目虚拟环境时，可使用已安装依赖的 `python` 执行同一命令。用例覆盖首次打开、空白输入、昵称与性格、会话切换与删除、损坏记录、磁盘保存失败、回复重试、空回复和流式中断。

安装用例将完整运行资源复制到临时目录，并检查带空格路径可以启动。Windows 启动器用例建立最小 `.venv`，在外部 CLI 边界使用测试替身，确认双击脚本选择项目解释器、切换到项目目录并传递启动参数。

这些检查使用临时会话和模拟模型回复，不会验证真实 DeepSeek 服务连通性，也不等同于在全新机器上从网络安装所有依赖。

## 浏览器检查

页面或资源变化后，使用无真实密钥、临时会话目录的本机预览，检查：

- 1440px 桌面和 390px 手机宽度，页面没有横向溢出；手机侧栏初始收起。
- 标题、叶片插画、背景和字体回退正常。
- 编辑并保存伴侣设定后，页面同步更新。
- 开场话题只填入输入框，由用户确认发送。
- 完整项目运行资源复制到另一目录后仍可加载。
