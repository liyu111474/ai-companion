# v0.1.0 · 小叶子 AI 伴侣

基于 Streamlit 和 DeepSeek 的日常陪伴聊天应用，提供植物系界面、自定义伴侣设定和本地会话管理。

- 支持流式显示回复、切换与删除聊天记录，以及失败后重新回复。
- 完整提供样式、叶片插画和主题配置，保留桌面与手机布局。
- Windows 启动器优先使用项目 `.venv`，并支持传递 Streamlit 启动参数。
- 增加安装回归检查、MIT 许可证、第三方资源说明、公开文件清单及开发发布流程。

验证范围和最新结果见 `.verification/app-review.md`。自动测试使用 API 测试替身；真实回复需使用自己的有效 DeepSeek 密钥。浏览器检查及项目副本启动通过，不代表已验证全新机器或其他操作系统的安装。

聊天记录和真实密钥保留在本机，未纳入公开文件。
